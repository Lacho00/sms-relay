# Brand

The mark is the relay itself: an SMS bubble feeds one hub, and the hub fans out to two
destinations (Telegram and the webhook). The bubble has the same shape as the
sms-forwarder app icon, so the two projects read as one system.

| File | Use |
|---|---|
| `logo.svg`, `logo-640.png` | Avatar with background: Telegram bot, GitHub |
| `logo-small.svg` | 48 px and below: no text lines in the bubble, thicker strokes, solid end points |
| `logo-mark.svg` | No background, for the README on light and dark themes |
| `social-preview.png` | GitHub social preview, 1280×640 |

Colours: indigo `#1E1B4B` (background), white `#FFFFFF`, purple `#5B4BDB` (shared with
sms-forwarder), lavender `#A5B4FC`, `#7C6FF0` (mark only), amber `#FBBF24` (the hub).
The banner uses Space Grotesk Bold and Inter (SIL Open Font License).
